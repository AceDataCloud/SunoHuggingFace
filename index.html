1. Connect your Ace account

Sign in → Applications → General application → copy API Key, or Manage Keys → Create. Check Suno access, expiry, Allowed APIs and balance. Allow both /suno/audios and /suno/tasks.

The token stays in this tab's memory and is sent only to api.acedata.cloud. No shared owner key, cookies or browser storage are used. Generation uses your Ace balance; HF credits do not apply.

2. Retrieve an existing task

Already submitted a song? Query that same task ID. A preview audio URL does not mean completion.

Queries are manual and at least 15 seconds apart. Keep the ID if the tab is closed. No new generation is submitted by this button.
